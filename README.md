# Cardflow

Free browser-local tools for planning trading-card sorting and scanning workload. No card photos, collection lists, accounts, or personal data are uploaded.

## Tools

- [Trading-card backlog deadline planner](https://trumpcoinofficial25-ship-it.github.io/)
- [Sort and scan workflow planner](https://trumpcoinofficial25-ship-it.github.io/sort-scan-workflow-planner/)
- [Manual vs machine capacity planner](https://trumpcoinofficial25-ship-it.github.io/manual-vs-machine-capacity/)

Calculations use only values entered in the browser and are planning estimates, not guarantees.
